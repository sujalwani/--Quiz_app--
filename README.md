
🎯 Quiz Game

A simple and interactive Quiz Game built using HTML, CSS, and JavaScript. The application presents multiple-choice questions, tracks the user's score, displays progress, and shows the final result at the end of the quiz.

🚀 Features
Start Quiz screen
Multiple-choice questions
Real-time score tracking
Progress bar indicator
Instant answer validation
Responsive design for mobile and desktop devices
Result screen with performance feedback
Restart quiz functionality
🛠️ Technologies Used
HTML5
CSS3
JavaScript (ES6)

🎮 How to Play
Click the Start Quiz button.
Read the question carefully.
Select one of the available answers.
Correct answers increase your score.
After answering all questions, view your final score and feedback.
Click Restart Quiz to play again.
